# Tanzil Jawas Portfolio

A static portfolio website built with HTML, CSS, and JavaScript. It presents personal projects, skills, education, experience, and contact links.

## Features

- Responsive portfolio layout
- Terminal-inspired introduction and interactive interests
- Project cards and profile sections
- Email, GitHub, LinkedIn, and social links

## Run locally

No build step is required. Clone the repository and start a local static server from its root:

```sh
git clone https://github.com/tanziljws/Portofolio-web.git
cd Portofolio-web
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. You can also open `index.html` directly, though a local server is closer to how the site is served online.

## Project files

- `index.html` — page content
- `styles.css` and `typewriter.css` — visual styles and animations
- `script.js` — interactive behavior
- `img/` — image assets

The page loads jQuery and Font Awesome from public CDNs.
